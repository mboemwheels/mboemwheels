# MB OEM Wheels

[MB OEM Wheels](https://mboemwheels.com/) is an independent reference for factory Mercedes-Benz wheels. Look up any OEM Mercedes wheel by part number and see its sizes, offsets, finishes, Hollander numbers and the cars it came on, across 85 chassis from the W205 C-Class to the W167 GLE.

**Got factory Mercedes wheels?** Send us a photo of your car and we'll feature it on [mboemwheels.com](https://mboemwheels.com/).
